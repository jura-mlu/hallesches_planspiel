# Hallesches Planspiel – Strategische Vertragsverhandlung

In diesem Repository liegen die Unterlagen, mit denen sich ein eigenes Planspiel nach dem Vorbild des Halleschen Planspiels „Strategische Vertragsverhandlung“ durchführen lässt. Enthalten sind der Sachverhalt und alle Begleitinformationen des ersten Planspiels (Stand Oktober 2026).

## Ablauf

Zwei Teams verhandeln einen Kaufvertrag über eine Schankanlage: Team Käufer vertritt die Hallesches Bierhaus GmbH, Team Verkäufer die Beverage Tech GmbH. Beide Teams erhalten den allgemeinen Sachverhalt (Teil A), dazu jeweils nur die eigenen vertraulichen Informationen (Teil B oder C). Nach der Verhandlung wird der ausgehandelte Vertrag anhand der Bewertungsmatrix (Teil D) ausgewertet.
